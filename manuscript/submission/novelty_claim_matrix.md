# Revised novelty claim matrix after closest-prior audit

| Candidate claim | Status | Reason / precedent | Approved replacement |
|---|---|---|---|
| EOG is the first framework to combine suitability and connectivity | Prohibited | Functional habitat and habitat-network/occupancy frameworks already combine these elements | EOG tests whether a structural term earns an incremental held-out claim relative to an explicit reference |
| SDMs ignore spatial configuration or dispersal | Prohibited | BAM/accessibility, patch-effect SDMs, dynamic/mechanistic SDMs and connectivity-augmented models exist | Pointwise support and connectivity are distinct estimands; some SDMs represent both, others do not |
| Occurrence anchoring is novel | Prohibited | Occupied-neighbour, nearest-occupied-patch and source-conditioned metapopulation concepts are established | EOG uses **outer-training-only** occurrence anchors as a leakage-control rule |
| Varying thresholds/scenarios is novel | Prohibited | Habitat-network threshold sensitivity and broader connectivity uncertainty frameworks exist | EOG predeclares an ensemble and evaluates its aggregate structural diagnostic without held-out winner selection |
| Connected frequency is a new connectivity probability | Prohibited | It is not biologically calibrated and is not a movement probability | Connected frequency is the fraction of declared graph scenarios linking a target to a training anchor |
| A-Islands proves graph structure beats SDM | Prohibited | Its reference is frozen climate support + nearest source, not every connectivity-aware SDM | A-Islands shows added conditional incidence information beyond the two frozen controls |
| Tanzania proves current flow is superior | Prohibited | One 14-fragment system and spatial-block intervals are uncertain | The tested generic EOG term is adverse under primary LOSO beyond this strong current-flow reference |
| The positive/negative contrast identifies the causal reason EOG works or fails | Prohibited | Systems differ in taxa, landscape, endpoint and reference | The contrast establishes an empirical applicability boundary; causal explanations remain prospective hypotheses |
| Source-to-result fingerprints make ecological conclusions true | Prohibited | Fingerprints establish identity/provenance only | Audit artifacts make design timing, failures and generated outputs inspectable |
| EOG provides reference-conditioned incremental structural validation | Approved | This is the narrow combined contribution supported by current benchmarks | Lead novelty statement |
| EOG's validation architecture can return a negative result against a stronger connectivity reference | Approved | Tanzania demonstrates this under the frozen protocol | Lead falsifiability/scope statement |
| The value of a structural feature depends on what the reference model already represents | Approved | Supported by A-Islands vs Tanzania without comparing effect magnitudes | Main cross-system conceptual conclusion |
