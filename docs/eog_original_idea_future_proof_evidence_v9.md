# Original EOG future-proof evidence leverage — v9

## Question

Previous evidence planners asked which measurement most quickly identifies the current
ecological target.

v9 asks a different question:

> **Which measurement best protects today's universal ecological certificates against
> future enlargement of the admitted world universe?**

These objectives need not agree.

## Baseline

The current B0 universe contains the surviving reference world for each source after
the frozen 25% positive-occurrence evidence.

The future growth pool is the v8 all-source compatible world pool.

Current universal node certificates are scored before any diagnostic action.

## Actions

Three truth-consistent known-truth diagnostics are compared:

- source identity;
- barrier level;
- analyst traversability rule.

Source evidence may shrink B0 immediately.

Barrier and analyst diagnostics have **zero current B0 contraction by construction**,
because B0 already uses the reference barrier/rule, but they can exclude whole classes
of future worlds.

This makes them a clean test of future-only information value.

## Two objectives

1. current contraction — remove as many current B0 worlds as possible;
2. future proofing — maximize mean normalized certificate lifetime under the filtered
   future world-growth pool.

If the optimal actions differ, generic present uncertainty reduction is not a sufficient
evidence-design criterion for EOG robustness.

## Boundary

This is a known-truth leverage experiment.  It does not assign field costs or outcome
probabilities to source/barrier/analyst diagnostics.
