# Target-sufficient quotient in finite BAM worlds

## Why this is the capstone

The finite-world programme now contains several representations of the same
occurrence-compatible ecological alternatives:

- exact parameter worlds;
- complete current A/B/M/tau states;
- exact future maps under declared transformations;
- binary future decisions.

These representations should not be forced into one universal hierarchy.

The correct object for a declared target (T) is its quotient:

[
w\sim_Tv
\iff
T(w)=T(v).
]

All worlds in one target class are interchangeable **for that target only**.

## Current-state relation to a target

Let (P_C) be the current-state partition and (P_T) the target partition.

Four relations are possible.

### Equal

Current-state identity and target identity coincide.

### Current state refines target

[
P_C \preceq P_T.
]

Current state is sufficient but over-detailed: some distinctions between present
mechanism states cannot change the target.

### Target refines current state

The target distinguishes worlds that the present-state representation merges.
Current-state identity is insufficient.

### Incomparable

Both occur in the same fiber:

- some present-state distinctions are irrelevant to the target;
- some present-state aliases split under the future target.

This is the strongest warning against treating “the current mechanism state” as the
universal inferential endpoint.

## Joint target suite

For several declared targets, the coarsest exact representation sufficient for all of
them is the partition induced by their joint target signature.

For the frozen programme this is the tuple:

[
(D_{climate},D_{biotic},D_{barrier}).
]

It is generally much coarser than parameter-world identity and can have a nontrivial
relation to the current BAM-state partition.

## Boundary

This is finite partition algebra, not new mathematics.

The purpose is to define precisely what EOG should carry forward to external empirical
validation:

> **not one selected true world, but the quotient class of all surviving worlds that
> are equivalent for the declared ecological target suite.**
