# Original EOG source-history memory experiment — v21

## Question

v18-v20 showed that source placement, confluence and turnover matter even when source
count is held fixed.

v21 asks the stronger history question:

> **If the final source set is exactly the same, can the order in which those sources
> became active leave a detectable distributional memory?**

## Same final state, different history

Each three-source network is assigned the same activation-time multiset {0,2,4}, but
the times are permuted among the same three source identities.

The final:

- source identities;
- source count;
- A/B field;
- M graph;
- equilibrium reachable union

are therefore identical.

Only source activation order differs.

## Two kinds of memory

### Occupancy memory

At a finite checkpoint two steps after the last source becomes active, different
histories may have colonized different subsets of the eventual equilibrium union.

This memory must disappear at equilibrium because all final sources and the graph are
the same.

### Provenance memory

Even after equilibrium occupancy becomes identical, the source attaining the earliest
arrival at a node can still depend on activation order.

Thus the final spatial distribution may forget history while the provenance map
remembers it.

## Connection to the distributional-watershed idea

This distinguishes:

- final water extent;
- from which upstream basin the water first arrived.

In EOG terms, the static realized distribution can converge while its distributional
history remains non-identifiable from the final state alone.
