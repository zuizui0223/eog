# EOG × BAM: one geographically systematic A/B/M measurement error

## Main goal

The previous EOG × BAM analysis (PR #680) allowed one incorrect
**individual binary read**, anywhere in a nonadaptive panel.
Repeated readings of one local A/B/M bit were permitted as separate
opportunities, and all 144 ambiguous current-G observations were
resolvable within 9 individual reads in the frozen finite worldset.

This follow-up asks what happens when the **entire geographic site**
may be systematically mischaracterized. Such an error can affect
A, B and M measurements at that site together and persist across
multiple repeats. Simply triplicating an assay at the same physical
site is therefore **not an independent error correction**.

This is a prospective protocol for a new exploratory readout of the
**same already-exposed 12 landscapes, 768 parameter worlds, 129
true-G maps and 2627 observed-D maps**, not a natural field
replication or new biological inference.

## Error model

One *physical grid location* produces one three-bit profile
\`(A_i,B_i,M_i)\`, an ideal complete direct measurement of all three
constraint types. The whole profile at at most **one** selected
location can be changed arbitrarily; all other selected sites return
their exact three-bit state.

At most one site corrupted is a bounded-error assumption, not a
calibrated probability or guarantee that one field specimen is
sufficient. Repeating A/B/M measurements within a single site
provides **no additional independent site** in this model.
Each geographic site has equal cost 1, with three ideal axis-bit
readings. The cost model does not charge travel or sample preparation.

## Exact nonadaptive identification criterion

For any two candidate BAM mask triples \`u,v\` producing different
M-release span **signs**, their measured three-bit profiles must
differ at at least **three distinct geographic sites** to be
robust to one arbitrary corrupted site.

This is a block-Hamming error correction result: radius-one balls
about two distinct-sign codewords are disjoint if and only if their
site-level Hamming distance is at least three.

Let \`x_i\` be 0/1 choice of geographic site i, and
\`d_i(u,v)\` indicate whether the entire A/B/M triple differs.
Find \`min sum_i x_i\` with
\`sum_i x_i d_i(u,v) >= 3\` for every opposite-sign candidate pair.
The zero-site-error baseline uses >=1. The solver is
\`scipy.optimize.milp\` with integer variables, binary bounds and
zero requested MIP gap. Nonoptimal results terminate the run.

**Structural IMPOSSIBLE** is a distinct outcome: if any opposite-sign
pair differs at fewer than three geographic sites **over the entire
available grid**, no amount of measuring or remeasuring those
same sites can certify the response sign under the stated error
bound. Do not report an infinite number as a valid finite
sample-size estimate, and never drop these cases from denominators.

Each resulting candidate panel is independently checked against
every compatible true mask triple and **every possible single-site
arbitrary three-bit corruption**, including unchanged readings.
The observed answer remains compatible with its true world, and no
opposite target sign may remain among candidates with up to one
corrupted site.

## Bounds and interpretation

This is a fixed-site-set, nonadaptive optimum, not an optimal adaptive
query tree. It operates only on the preexisting finite set of possible
BAM constraint worlds. A/B/M axes are measured perfectly together at
each selected site except at one completely unreliable site. The
reported possible/impossible distinction can change if the spatial
grid or available independent diagnostics change.

Actual ecological surveys face additional error sources: hidden
occupancy states, time variation in resource and connectivity,
spatially correlated measurement error affecting several sites,
nonrandom access and costs, and mechanisms missing from the finite
model. These are not resolved here.

No original EOG-WF endpoint, manuscript, 768-world result or
1,344-pair conclusion is changed. Failure to identify the M-release
span sign under one corrupted geographic site is a property of the
specified evidence model, not evidence that true dispersal is
biologically impossible.

## Canonical descriptive results

Of the **2,627 distinct observed-D finite-world fibres**,
**2,483** already give unanimous M-release span direction without
any further assay, leaving **144 initially ambiguous**.

| Distinct-D class | Exact minimum independent geographic sites | Count |
|---|---:|---:|
| Target already unanimous | 0 | 2,483 |
| Correctable despite one arbitrary bad geographic site | 3 | **100** |
| Structurally unidentifiable under one bad geographic site | Not finite | **44** |

The **44 impossible D** arise because some opposite-sign candidate
mask pairs differ at only **one geographic node in 25 cases**, or
**two nodes in 19 cases**, *even across the complete candidate grid*.
No additional replicates or A/B/M axes at those same nodes can
create a third independent spatial separation.

In the zero-site-error baseline with full three-bit profiles,
minimum distinct site counts were **0:2,483; 1:143; 2:1**.
With one site-wide systematic error, all 100 feasible ambiguous
observations require **three different geographic sites**, i.e.
nine ideal axis-bit readings in total, and the remaining 44 have
no error-correcting panel in this frozen source universe.

For each of the 129 original true-G classes, a guarantee requires
identification for **every** possible omitted-positive observation D.
The number of fully robust G classes is **86/129 before additional
assays, and 113/129 once three distinct sites can be measured**.
Further sites, up to the entire supplied grid, cannot resolve the
remaining **16/129** true-G classes under this one-bad-site guarantee.

These numbers are not empirical error rates. They are structural
finite-model results conditional on complete current mapping except
one occupied-cell omission, ideal full A/B/M site profiles, and an
upper bound of one systematically corrupted geographic site.

## Comparison with prior one-bad-reading result

PR #680 allowed *one individual binary read* to be wrong, with
each repeated read as a separately corruptible unit. Under that
model up to **nine individual reads** could resolve all 129
true-G classes in the same finite source. The current model can
also involve nine axis-bit readings (three whole A/B/M site profiles),
but demands **three independently located sites**.

The residual 16 classes are not a contradiction of PR #680:
their source-world pairs lack enough independent spatial differences
to correct one geographically shared systematic error. The
error model, unit cost and required independence have changed.
