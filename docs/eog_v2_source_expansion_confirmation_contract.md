## Frozen nested source policy

### Outer prediction

For each outer fold, sources are:

`base sources + positive outer-training targets`.

Outer-test labels are unavailable to source construction. Flipping all outer-test labels must change every source-derived outer-test feature by exactly `0.0`.

### Training calibration

Source-derived training features are generated by an inner fold. Each inner-heldout positive target is excluded from its own source set. Thus no positive training row receives a zero-cost or exact-source feature merely because its own label is positive.

A deliberately leaky expanded-dynamic model is retained only as an audit control and is not a scientific reference.

## Frozen confirmation gates

The confirmation passes only if all conditions hold:

1. outer-test label invariance maximum absolute feature difference is exactly `0.0`;
2. every confirmation seed contains positive inner-heldout rows that are explicitly self-excluded;
3. mean `expanded_dynamic` log loss is at least `0.05` lower than the mean of the **seedwise best** among `fixed_dynamic`, `expanded_nearest`, and `expanded_pressure`;
4. `expanded_dynamic` beats that seedwise best non-leaky reference in at least `6/8` seeds.

The leaky audit model does not enter the promotion gate.

## Interpretation boundary

Passing this synthetic confirmation would support only a leakage-safe source-expansion implementation under the known synthetic propagation process. It would not establish an empirical colonisation probability, empirical superiority, or a universal rule that every observed training occurrence should be treated as a contemporary source.
