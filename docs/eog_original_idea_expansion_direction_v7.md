# Original EOG expansion-direction experiment — v7

## Why v7 exists

v6 directly refuted the idea that impossibility certificates are intrinsically more
persistent than reachability certificates.

The missing qualifier is the **direction of world expansion**.

If a newly admitted world is more restrictive than an already compatible reference
world for the same source, its reachable set is a subset.  It cannot make a previously
impossible node reachable, but it can remove a previously universal reachable node.

If a new world is more permissive, the logic reverses.

## Frozen classification

For each source that survives the v6 baseline evidence, every parameter world is
classified relative to that source's reference world:

- restrictive: strict reachable-set subset;
- permissive: strict superset;
- equivalent;
- incomparable.

The source set is held fixed for the directional experiments.

## Expected conditional rule

The exact finite-set expectation is:

- restrictive expansion protects robust impossibility;
- permissive expansion protects robust reachability.

The empirical part asks whether the opposite certificate type actually erodes in the
randomized landscapes, and how much additional fragility comes from incomparable worlds
or from admitting entirely new source hypotheses.

This converts the failed unconditional statement from v6 into a conditional statement
that can say when reverse-impossibility reasoning is justified.
