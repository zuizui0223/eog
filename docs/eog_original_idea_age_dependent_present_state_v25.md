# Original EOG age-dependent present state — v25

## Question

v24 established that final occupancy and source provenance can be identical while
colonization-age state differs.

v25 asks whether that hidden age memory can matter for a present ecological state.

## Frozen process

A single synthetic process was fixed before scoring:

- common present horizon T* = maximum finite non-source first-arrival time across the
  three frozen activation histories;
- maturation lag = 2 structural propagation steps;
- a non-source node is mature at T* when T* - first_arrival >= 2;
- occupancy persists;
- no abundance, extinction, density dependence or fitness is added.

The point is not that two steps is biologically universal.  It is a controlled
known-truth test of whether hidden distributional history can become present-state
relevant under one prospectively fixed lagged process.

## Key comparisons

The hierarchy is:

final occupancy
< source provenance
< colonization age / first arrival
< exact activation history.

v25 adds a target below full age identity:

mature/not-yet-mature present state.

It asks whether:

1. histories hidden by occupancy + provenance can differ in present maturation;
2. some age differences are too fine to matter for the maturation target;
3. unique-origin as well as confluence zones can carry present-state legacy.

A favorable result establishes only possibility under the frozen synthetic process, not
empirical priority effects.
