# Original EOG multi-source placement experiment — v18

## Question

How much does source **arrangement** matter when source count is fixed?

The experiment reuses the v5 directed virtual landscapes and changes only the placement
of additional source populations.

## Two source geometries

Every source set contains the same frozen upstream anchor.

Additional sources come from the upstream half of the A/B-permissive landscape.

- clustered: add the nearest available source to the anchor first;
- dispersed: add the source farthest from the existing selected set first.

Both designs are nested from one to two to three sources.

## Four ecological consequences

The same source number can affect four different quantities:

1. reachable coverage;
2. overlap / confluence of source basins;
3. ambiguity of source attribution downstream;
4. insurance against losing one source population.

A placement that maximizes coverage need not maximize redundancy.

## Strong comparison

v18 also asks whether two dispersed sources can cover more of the landscape than three
clustered sources.

A positive result would make the conservation statement sharper than "source number and
placement both matter":

> source count is not even ordinal with respect to reachable coverage when source
> locations differ.

## Boundary

This is topology and reachability, not demographic population viability.

Source-loss retention is a structural redundancy measure, not extinction probability.
