# Evidence routing for future targets in finite BAM survivor fibers

## Setup

Let (Theta) be a finite parameter-world universe and (SsubseteqTheta) the current
survivor fiber after occurrence evidence.

Let

two worlds whose complete (C) values are equal.

## T1 — Present-state sufficiency criterion

For truth (	heta_*), define its current-state alias class inside the survivor fiber:

[
A_C(	heta_*)
=
{	hetain S:C(	heta)=C(	heta_*)}.
]

Even the **complete** present-state evidence library can identify future target (T)
for truth (	heta_*) if and only if

[
|T(A_C(	heta_*))|=1.
]

### Proof

Complete present-state evidence can eliminate every survivor whose (C) differs from
truth, but no survivor inside (A_C(	heta_*)).

Therefore the residual target set after arbitrarily complete C-type measurement is
exactly (T(A_C(	heta_*))).  It is a singleton if and only if the target is identified.

## Corollary — Dormant aliases create an evidence-class impossibility

If there exist

[
	heta_1,	heta_2in S
]

such that

[
C(	heta_1)=C(	heta_2)
]

but

[
T(	heta_1)
eq T(	heta_2),
]

then **no quantity of present-state C measurement can identify T** while both worlds
remain admissible.

The problem is not insufficient sampling density.  The evidence class itself lacks a
distinguishing dimension.

A parameter-sensitive, challenge-based, or otherwise transformation-sensitive evidence
channel is required.

## T2 — Target-specific evidence need not identify the parameter world

Let the truth target class be

[
[	heta_*]_T
=
{	hetain S:T(	heta)=T(	heta_*)}.
]

An evidence design for T need eliminate only

[
Ssetminus[	heta_*]_T,
]

not every parameter-world alternative in (S).

Hence, under a shared finite measurement library,

[
b(T)leq b(	heta),
]

where (b(	heta)) is exact parameter-world identification burden.

Strict inequality is possible whenever some parameter aliases share the truth target.

The Phase-VI W1 benchmark observed strict parameter-assay savings for every truth under
all three frozen transformations.

## T3 — Evidence routing precedes evidence ranking

For a future target unresolved at E1, first evaluate the complete-state alias class.

### Route 1: state-resolvable

If

[
|T(A_C(	heta_*))|=1,
]

then present-state evidence is in principle sufficient.  Evidence design may search for
the smallest A/B/M/tau measurements that isolate the target-relevant state class.

### Route 2: state-impossible

If

[
|T(A_C(	heta_*))|>1,
]

then collecting more evidence of the same complete-state type cannot solve the target.
The candidate evidence library must include a variable that distinguishes dormant
parameter aliases.

This yields the exact routing rule:

[

]

## Frozen Phase-VI examples

### Climate shift

Of 132 W1 climate binary decisions unresolved from G alone:

- 122 were state-resolvable;
- 10 were state-impossible.

All 132 were resolved by one A-level assay.

### Biotic stress

All 270 unresolved binary decisions were state-resolvable.

Parameter-only evidence required two assays in 110 truths, while the combined library
resolved every case with one channel.

### Barrier restoration

Of 68 unresolved binary decisions:

- 58 were state-resolvable;
- 10 were state-impossible.

For the exact future map, 88 truth cases were state-impossible, showing that evidence
routing depends on target resolution.

## Claim boundary

This criterion is elementary finite-partition logic and is not claimed as new
mathematics.

The BAM contribution is the explicit placement of this routing step inside an
occurrence-conditioned inverse A/B/M survivor fiber with prospectively frozen future
transformations.

Exact parameter-coordinate assays in the benchmark are synthetic information channels,
not ready-made field protocols.
