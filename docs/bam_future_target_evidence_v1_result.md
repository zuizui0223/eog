## Present-state evidence can be sufficient, unnecessary, or fundamentally insufficient

With parameter evidence alone:

But with the combined library, all 270 unresolved decisions required only **one**

So latent parameter measurement is not uniformly superior.  For this transformation,
present-state information can be the more efficient discriminant.

This is another target-resolution effect: exact spatial response can require information
that the coarser gain/no-gain decision does not.

## Dormant climate alias: the clean counterexample

The preregistered S11 fiber contains 36 W1 same-G parameter worlds and one complete
current BAM-state class.

Two original truth worlds lie in that fiber:

- `A_broad|B_none|M_D2.01_P0_H3`;
- `A_broad|B_none|M_D2.01_P1_H3`.

For both truths:

- climate binary target classes: 2;
- complete current-state evidence: **insufficient**;
- minimum parameter design: **A_level only**;
- parameter assay count: **1**.

Thus even perfect knowledge of present A/B/M/tau cannot answer this future question.
The missing information is a latent niche parameter that is dormant under current
conditions and exposed by the climate transformation.

## New evidence-design rule

The earlier stopping rule was:

[
|D(S)|=1.
]

Phase VI adds the measurement consequence.

If (D(S)) is not a singleton, do **not** automatically collect more present-state
data. First ask whether the disagreement occurs inside a current-state equivalence
class.

- If no, current-state measurements may resolve the decision.
- If yes, present-state measurement is information-theoretically incapable of resolving
  the future target; a parameter-sensitive or transformation-sensitive evidence channel
  is required.

This turns dormant-alias detection into an evidence-routing rule.

## Boundary

The parameter assays are exact synthetic channels, not field protocols.

A one-channel design does not mean inexpensive or easy field measurement.

Likewise, the frequency with which a parameter appears in one canonical minimum design
does not establish causal importance.  Correlated finite-world structure can make a
parameter informative about a target generated through another axis.
