# Great Lakes low-head-dam A/M external bridge v1

## Role

This is a **retrospective external bridge**, not fresh confirmatory evidence. The Dryad
landing page and article-level aggregate results were visible before the bridge was
designed.

The dataset contains paired barrier/reference streams, repeated surveys from 1996/97
and 2023, site-level habitat measurements, and species-level catch/effort. That makes it
suitable for testing whether finite ecological worlds can be contracted by later
positive observations without changing the world universe.

## Why primary B is unrestricted

The released schema contains habitat, barrier/location, sampling effort and fish
assemblage observations, but it does not supply a predeclared causal interactor that
can defensibly be turned into BAM's B axis without post-hoc biological assumptions.

Primary empirical worlds therefore use G = A ∩ M with B unrestricted.

This is intentionally an empirical A/M subfamily of BAM, not a claim that all three BAM
axes have been measured.

## Frozen A

Seven habitat variables from the released habitat table are used together:

- width;
- max depth;
- clay, silt, sand, gravel and boulder proportions.

All 90s habitat nodes define response-independent robust scaling and four frozen
environmental-distance thresholds. Species' 90s positive nodes become support anchors
only after those thresholds are fixed.

## Frozen M

Physical nodes are ordered stream sites. Adjacent segments are connected within each
side of the barrier/reference location.

Candidate worlds cross:

- barrier closed/open;
- movement horizons 1, 2 and 5 graph steps;
- one unrestricted open world.

Reference streams are always crossable at the corresponding reference location.

## Evidence

90s positives contract the 35-world A/M family. 2023 positives are then held out as
strict ecological witnesses.

Nondetection is never treated as hard absence.

The bridge asks whether heldout positives falsify frozen worlds, not whether the method
reproduces the article's regression effects.
