# Original EOG ideas tested with BAM and finite virtual worlds

## Purpose

This programme uses virtual worlds as a controlled laboratory for the questions that
motivated EOG before the later BAM-identifiability work.

BAM is not the endpoint.  It is one way to build known-truth ecological worlds with
separate abiotic, biotic and accessibility constraints.

## Experiment matrix

| Original EOG idea | Virtual-world contrast | Quantity scored |
|---|---|---|
| suitable does not mean reachable | same target viability, barrier open vs closed | local A versus first-passage reachability |
| IBE is pathwise, not only endpoint distance | environmentally similar endpoints separated by an impossible intermediate state | endpoint distance versus pathwise reachability |
| stepping stones matter | direct movement impossible, intermediate node absent/present | target reachability and first-arrival depth |
| landscapes can contain bottlenecks or redundant routes | same endpoint occurrences, one route vs two independent routes | path count and knockout sensitivity |
| occurrences need not identify one history | direct versus stepping history with same observed endpoint set | compatible-world count and first-passage structure |
| time can break static aliases | same final distribution, different arrival order | static versus temporal survivor fiber |
| impossibility must weaken when more worlds are admitted | restrictive universe expanded by a permissive world | possible/robust-exclusion monotonicity |

## Why BAM still belongs

BAM remains useful whenever the experiment needs to control whether a pattern comes
from:

- A: local abiotic viability;
- B: biotic permissibility;
- M: accessibility.

But a virtual world can additionally contain:

- environmental continuity along a path;
- geographic movement limits;
- explicit barriers;
- stepping-stone nodes;
- source identity;
- directed branching;
- bottlenecks;
- temporal order.

This allows the programme to test the original EOG claim at the level where it was
actually proposed.

## What counts as success

The desired outcome is not that all seven hypotheses are favorable.

A useful known-truth programme must be able to show:

- where the original intuition is exactly true;
- where it fails;
- what evidence distinguishes competing worlds;
- which quantities are not identifiable even with complete occurrence coverage.

Any failed hypothesis remains in the result and determines the next design.

## Next stage after v1

If the six canonical archetypes behave as declared, v2 should no longer add arbitrary
examples.  It should randomize the same mechanisms across larger landscapes and ask
how often each phenomenon occurs as a function of:

- barrier density;
- stepping-stone density;
- environmental autocorrelation;
- route redundancy;
- source number;
- observation timing;
- A/B/M restriction.

That stage tests generality of the original EOG ideas rather than their existence.
