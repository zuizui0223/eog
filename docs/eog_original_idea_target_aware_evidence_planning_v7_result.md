## The next action depends on the target

Target-optimal first actions were:

- source identity: **201** rows;
- barrier level: **37**;
- analyst traversability rule: **17**.

Target-aware and world-aware planners chose different first actions in **24** rows.

In **23/24** of those disagreements, the target-aware first action produced a strictly
smaller worst-case number of remaining reachability target classes.

So generic world-count reduction is not always the right evidence objective.

## Stopping before history is identified

The target-aware truth path stopped while retaining:

- multiple worlds in **90** rows;
- multiple sources in **18** rows;
- multiple worlds and multiple sources simultaneously in **18** rows.

Every target was nevertheless resolved.

This is the action-level form of the original EOG principle:

> **retain unresolved histories when they cannot change the ecological conclusion.**

## Relation to the current world-growth line

The current v6-v8 programme asks how robust a certificate is as the admitted world
universe grows.

This adaptive-planning result is complementary:

- world-growth analysis tells us which future worlds threaten a certificate;
- target-aware evidence planning tells us which diagnostic observation should be taken
  next when the goal is the ecological target rather than historical-world identity.

The next active evidence-design experiment can therefore use v8 threat counts as a
target-specific planning objective without reverting to full-world recovery.
