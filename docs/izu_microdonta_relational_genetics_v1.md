# Izu Campanula microdonta prospective relation-genetics validation

## Status

Frozen before MIG-seq2 / SNP genetic response generation.

The 2026 field collection already provides 125 individuals from five Izu islands, with
leaf material retained. Morphology has been measured, but no MIG-seq2/FST result is
admitted into this contract.

The purpose is not to test BAM decomposition recovery. It is to test the original EOG
relational claim:

Does response-blind occurrence-conditioned reachability among sampled populations
contain neutral genetic information beyond IBD and IBE?

## Islands

- Izu Oshima
- Toshima
- Niijima
- Shikinejima
- Kozushima

## Separation from existing analyses

Flower morphology, patterning and PST analyses already exist but cannot be used to tune
the EOG graph or choose a favorable genetic population unit.

The genetic response is opened only after the sample registry, geographic/environmental
distances, transition-world family, occurrence relation graph, pair order and validation
model ladder are frozen.

## Why this is the right next test

Zhoushan produced a small IBD+EOG improvement but an indeterminate strong-reference
failure. Ryukyu produced retrospective added information relative to current flow but
not beyond IBD.

The Izu test can be genuinely prospective because the leaf samples exist while the
MIG-seq2/FST response has not yet been generated or viewed.


## Primary population unit frozen before genetics

The primary genetic unit is now fixed at the five islands, yielding ten unordered
population pairs.

Individual field sites remain in the registry for provenance and for constructing
response-free spatial relations, but site-level genetic grouping cannot replace the
island-level primary endpoint after genotype access.  This is especially important for
Niijima, where several field sites were sampled.

The next required object is a 125-row response-free sample registry with sample ID,
island, site ID, coordinates and leaf-availability status.  No genotype-derived field
is permitted in that registry.
