# Known-truth BAM v2.2 — direct mechanism evidence result

## Question

After complete presence/absence and known-truth occupied-node colonisation timing, v2.1 still identified only 6/64 truth BAM worlds.

v2.2 asks whether idealized direct measurements of A, B and M resolve that ambiguity.

## Unique truth recovery

| Evidence | Truth uniquely identified |
|---|---:|
| v2.1 baseline | 6/64 = 9.375% |
| + direct A | 8/64 = 12.5% |
| + direct B | 7/64 = 10.94% |
| + direct M | 9/64 = 14.06% |
| + direct A+B | 9/64 = 14.06% |
| + direct A+M | 18/64 = 28.125% |
| + direct B+M | 16/64 = 25% |
| + direct A+B+M | 32/64 = 50% |

All frozen exactness/ceiling hypotheses were supported.

`5912231d6b8d04fd1cbb3540bf137562c394aca9fc40069486d6350ee7fff9f0`

## Main result

Even an idealized observer who knows the complete realised A mask, B mask, M accessibility mask and full M first-arrival vector does not always recover the parameter world that generated them.

Complete BAM-state equivalence classes were:

- size 1: **32 truth worlds**
- size 2: **32 truth worlds**

Therefore the final 50% non-identification is no longer an occurrence-sampling problem.

It is a **parameter-to-state aliasing problem**:

[
	heta_1 \neq \theta_2
quad\text{but}quad
(A_1,B_1,M_1,t_1)=(A_2,B_2,M_2,t_2).
]

No observation of those state variables can distinguish such parameterizations.

## Evidence value

M-specific evidence contributes more to unique recovery than A or B alone in this factorial, and the strongest two-axis gains are A+M and B+M. This does not mean movement is universally more important biologically; it means the frozen candidate grid contains more residual distinguishable variation on M after the v2.1 baseline.

## Consequence for EOG

EOG should distinguish at least three inferential targets:

1. **world compatibility** — which declared worlds are contradicted?
2. **state-mechanism compatibility** — which A/B/M states remain possible?
3. **parameter identification** — are the parameters that generate those states unique?

The v2.2 result shows that success at level 2 does not guarantee level 3.

A surviving parameter world therefore must not be reported as uniquely true unless its induced state is both evidence-compatible and injectively mapped back to the parameterization within the declared universe.
