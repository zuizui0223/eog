# BAM ecological expansion margin v1

## Question

Phase III measured logical distance from a decision-identified BAM survivor fiber to an
arbitrary same-G decomposition with the opposite decision.

That is a useful worst-case certificate, but a single A/B/M bit flip need not
correspond to a coherent ecological model.

Phase IV therefore asks:

> **How far must a prospectively declared ecological BAM parameter family be expanded
> before a same-G counterexample reverses the decision?**

## Frozen expanded lattice

The original 64-world universe remains embedded exactly.

### A — abiotic niche breadth

The two declared niche-radius states share the same center.

- level 0: frozen narrow radius;
- level 1: frozen broad radius;
- level -1: one linear radius step narrower than level 0;
- level 2: one linear radius step broader than level 1.

No center shift is added in v1.

### B — associate-range uncertainty

The four interaction modes are already the full 2×2 factorial of:

- obligate-partner requirement on/off;
- antagonist exclusion on/off.

The interaction logic is therefore not enlarged.

Instead the independently generated partner and antagonist distributions each receive
three frozen spatial levels:

- -1: one 4-neighbour erosion shell;
- 0: original frozen range;
- +1: one 4-neighbour dilation shell.

These are synthetic associate-range perturbations, not calibrated range-shift models.

### M — movement uncertainty

The original factorial uses two step radii and two time horizons.

The expanded lattice adds:

- a third step radius, 3.01 grid units;
- an extra-long horizon equal to frozen long horizon + landscape width.

Barrier permeability remains the original binary closed/open axis because both states
were already declared.

## Same-G condition

An expanded world can challenge a decision only if

[
A'\cap B'\cap M'=G
]

exactly.

Thus a counterexample cannot win merely because the parameter perturbation changes the
currently observed distribution.

## Interpretation

This margin sits between two earlier quantities:

1. Phase-II target identifiability inside the original 64-world family;
2. Phase-III unrestricted bit-level same-G completion margin.

Phase IV is still synthetic and finite.  It does not claim that its perturbation levels
are the true uncertainty set for any real species.

Its purpose is to test whether decision robustness survives a **structured ecological
neighbourhood** rather than only the original hand-declared factorial.
