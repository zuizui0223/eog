# Original EOG colonization-age memory experiment — v24

## Question

v23 left 81 source-history design rows unresolved even after complete occupancy and
equilibrium-provenance evidence.

v24 asks whether those aliases are genuinely ecologically identical or whether they
still differ in a hidden temporal state:

> **when did each occupied node first become reachable?**

## No new ecological mechanism

v24 does not add extinction, abundance, persistence or another transition rule.

It reuses the exact v21 activation histories and computes, for every non-source
equilibrium node:

- first structural arrival time;
- colonization age at one common row/design horizon.

Source nodes are excluded so the activation schedule cannot be read directly from the
source itself.

## Why age differs from provenance

Provenance asks:

- which source arrived first?

First-arrival state also asks:

- when did the first source arrive?

A node can therefore have identical source provenance under two histories but different
colonization age.

This can occur even in a unique-origin zone, where source identity is structurally
fixed but that source became active at a different time.

## Main target

The preregistered focus is the 81 v23 exact-history aliases after complete occupancy and
provenance evidence.

v24 tests whether a complete non-source first-arrival map:

- distinguishes some of those aliases;
- leaves others truly equivalent at this richer history-state level.

This is a target-equivalence audit before any new measurement or consequence model is
introduced.
