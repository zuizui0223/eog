# Original EOG target-aware adaptive evidence planning — v7

## Question

v6 showed that different evidence channels cross different inferential boundaries.

v7 asks the operational question:

> If the goal is the ecological reachability target rather than full historical-world
> identity, which measurement should EOG request next?

## Evidence actions

The frozen action library contains three direct categorical measurements:

- source identity;
- barrier level;
- analyst traversability rule.

Temporal evidence is deliberately excluded because the v6 temporal channel is a
composite truth-relative arrival-depth constraint rather than a single pre-outcome
categorical assay.

## Exact adaptive planning

For every current survivor fiber, v7 builds two complete finite decision trees.

The target-aware tree minimizes worst-case action depth until all surviving worlds share
one exact reachability set.

The world-aware tree minimizes worst-case action depth until one world remains.

No world probabilities are assigned.

## Why this matters

A generic uncertainty-reduction strategy may spend measurements distinguishing worlds
that are ecologically equivalent for the target.

Target-aware planning is allowed to stop while several histories remain unresolved,
provided those histories all imply the same reachability target.

This is the action-level version of the original EOG principle: retain uncertainty that
cannot change the ecological conclusion.
