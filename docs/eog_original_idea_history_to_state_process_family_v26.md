# Original EOG history-to-state process family — v26

## Question

v25 showed that hidden colonization age can affect a present-state target under one
frozen two-step maturation rule.

v26 asks what part of that result is general to the information retained by the
age-to-state process.

## Frozen process classes

Four mappings are compared:

1. history-blind occupancy — every reached node has the same state;
2. persistent threshold — age >=2, exactly the v25 mature target;
3. transient window — state ON only for ages 1–2;
4. saturating age class — 0, 1, 2, or 3+.

The family spans:

- complete erasure of age;
- monotone binary memory;
- non-monotone transient memory;
- finite multistate memory.

No process is fitted to the v25 result.

## Main test

Two histories can differ in colonization age while agreeing or disagreeing under any
coarser present-state map.

Therefore v26 tests whether “history matters” is actually shorthand for:

> **history matters only when the downstream ecological process preserves the part of
> history on which those histories differ.**

The saturating target is prospectively finer than both binary targets, which provides
an exact internal information-order check.

## Boundary

The mappings are qualitative synthetic process classes, not demographic models.
No abundance, fitness, extinction, density dependence or evolution is introduced.
