# EOG実証候補：Helgelandイエスズメの出生島→繁殖島データ（メタデータ監査v1）

**現在地：`HOLD_DIRECTIONAL_INDIVIDUAL_PROXY_ONLY`。** v23の仮想的な供給源由来タグに近い**個体単位の方向付き情報**を持つ、Glanvilleとは独立した生態系を見つけた。ただし、島全体の初回定着や供給源喪失の実証ができたとは判定しない。生物データ値の読み込み・解析・当てはめは**未実施**。

原本メタデータ台帳：`validation/eog_virtual_world_ecology_synthesis_v1/helgeland_directional_origin_preflight_v1.json`

## 1. 公開資料で実際に確認できること

ノルウェーのHelgeland諸島のイエスズメ *Passer domesticus* は、1993年からの標識再捕獲と遺伝情報による長期研究対象で、18島のメタ個体群が記載されている。ただし遺伝解析の詳細な対象は主として8島であるため、**18島を完全に同じ努力量で遺伝追跡したと扱わない**。

- [Saatoglu et al. (2025), Dryad DOI 10.5061/dryad.qfttdz0sx](https://doi.org/10.5061/dryad.qfttdz0sx)：公開READMEには `LRS.txt` に個体ID、出生島 `natal.island`、成鳥時の島 `adult.island`、孵化年 `year`、分散状況、生涯繁殖成功 `LRS` が記載される。 `ARS_Survival.txt` には `obs.year`、最初・最後に観測した島 `fiflok` / `laflok`、 `natal.island`、生存 `survival`、年次繁殖成功 `recruits` などが記載される。元論文の[DOI 10.1111/1365-2656.70049](https://doi.org/10.1111/1365-2656.70049)では、**移民と定住個体の繁殖成功・生存差はすでに解析済み**。
- [Saatoglu et al. (2024), Dryad DOI 10.5061/dryad.80gb5mkxh](https://doi.org/10.5061/dryad.80gb5mkxh)：SNP由来の母・父・子IDを持つ `SNPpedigree_GeneticArchitecture.txt`、出生島・孵化年・分散状況を説明する `GGAM_data_GeneticArchitecture.txt` などが公開資料に記載される。**2024年の鳥ID・島コードが2025年の公開表と完全に結合できることは未検証**。
- [Kuismin et al. (2019), Dryad DOI 10.5061/dryad.gqnk98sh8](https://doi.org/10.5061/dryad.gqnk98sh8)：遺伝的出身集団推定と標識再捕獲を照合する方法をすでに公表している。源流の推定方法そのものはEOGの新規性ではない。
- [Ranke et al. (2021), DOI 10.1111/1365-2656.13580](https://doi.org/10.1111/1365-2656.13580)：同じイエスズメメタ個体群の島間分散・空間構造の先行研究。対象島の多くは調査期間の大部分で個体群が存続している。

今回確認したのは**論文・公開READMEのデータ辞書**であり、CSV/TXTの実際の物理ヘッダー、個体ごとの欠測、遺伝的起源推定の確率、島別調査努力量はまだ確認していない。

## 2. Glanvilleとの決定的な違いと残る限界

Glanvilleの同年・異なるパッチで検出された全きょうだいは、母親が両地点を訪れたことを示しても**どちらからどちらへ**移動したかを自動的には示さない。

一方、イエスズメの `natal.island=A`、`adult.island=B` は、個体について**出生島Aから成鳥期の島Bへ**という方向付きの出生分散を表現できる。これが今回見つかった重要な進展。

しかし、**個体の出生地A→繁殖地B ≠ 島Bへの初回定着**。

- Bには以前から別の繁殖集団がいた可能性がある。出生分散を「空きパッチへの植民」と自動変換しない。
- 出生島が巣や標識再捕獲で直接分かる鳥と、遺伝的集団割当で推定した鳥には、識別過程と誤差の違いがある。記録ごとの区別は未確認。
- 2025年の分析は成功した移民の繁殖適応度を既に検証している。単純に「移民の方が有利」と再報告しても新規性はない。
- 出生地の推定に成鳥時点またはその後の遺伝・再捕獲情報を使うなら、**成鳥期の結果を予測する時点にその起源ラベルを先取りして投入することは情報漏洩**。retrospectiveな情報復元とprospectiveな予測は分離する。

## 3. EOGに使える証拠レベル

| 問い | 現時点の評価 |
|---|---|
| 個体の出生島と後年の所在島という方向付き変数が公開資料にあるか | **Yes：READMEで確認** |
| EOG v23の理想化された個体・供給源由来に近い観測経路があるか | **部分的にYes**（島間の出生分散） |
| 島ごとの初回定着源・植民順序を示しているか | **No：このメタデータでは支持されない** |
| 島全体の喪失後、別供給源が機能を補ったと示せるか | **未確認** |
| 2024年の血統表と2025年の繁殖・生存表を個体IDで安全に結合できるか | **未確認** |
| 新しい独立したEOGの予測精度・因果効果の評価を実施済みか | **No** |

本候補はGlanvilleと**異なる生態系**であり、方向付きの個体履歴が検証できる可能性がある。しかし、既存の2019・2021・2024・2025年の研究の結果や個体データに重複があるため、「完全に新しい盲検確認試験」とは呼ばない。

## 4. 実データを開く前に固定すべき工程

1. **同一ソースの固定**：2024年・2025年の実ファイル版、SHA-256、物理ヘッダー、個体ID・島コードの意味を、応答値なしで照合する。
2. **観測と推定の分離**：巣・再捕獲で出生島が既知の個体と、遺伝的割当で出生島を推定した個体を識別し、誤分類率や未割当を記録する。
3. **対象と比較対象の決定**：先行の移民対住民の適応度差の再発見を避け、由来集団の多様性が**後年の島別加入・その変動**を説明するかなど、先行研究と重複しない問いに絞る。島別の観測機会・母集団規模・距離/ネットワークの強い対照が必要。
4. **時間リークを防止**：予測時点までに利用可能な出自情報と、後の生存・繁殖結果を明確に区別する。
5. **不成立ならSTOP**：個体・島・年の物理的整合性や独立した調査努力量が得られなければ、真の初回定着・供給源喪失に関する主張へ拡張しない。

**今回の最終判定：`HOLD_DIRECTIONAL_INDIVIDUAL_PROXY_ONLY`。** 方向付き出生分散の公表記録はあるが、島レベルの植民・喪失の実証へはまだ進めない。遺伝子型や個体の生存・繁殖値の読み込みは**未実施**。EOG-WFの凍結分母と仮想世界v18–v23の結果は変更しない。
