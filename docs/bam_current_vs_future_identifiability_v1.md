# Current-state identity and future-target identity in finite BAM worlds

## 1. Parameter world as the common parent

Let a finite BAM parameter world be (	heta\in\Theta).

The current BAM state is a projection

[
C:\Theta\rightarrow\mathcal C.
]

A structured counterfactual transformation is another mapping

[
F:\Theta\rightarrow\mathcal F,
]

and a coarser decision target is

[
D=d\circ F.
]

Thus the diagram is

[
\theta\rightarrow C(\theta)
]

and

[
\theta\rightarrow F(\theta)\rightarrow D(\theta).
]

In general (F) need not factor through (C).

## 2. Dormant parameter aliases

Two parameter worlds are current-state aliases when

[
C(\theta_1)=C(\theta_2).
]

They are dormant-counterfactual aliases when additionally

[
F(\theta_1)\neq F(\theta_2).
]

Therefore identification of the current BAM state does not imply identification of a
future counterfactual target unless there exists a function (h) such that

[
F=h\circ C.
]

That factorization condition must be justified; it cannot be assumed.

## 3. What remains a true coarsening hierarchy

Because both exact future map and decision are deterministic functions of the full
parameter world,

[
\text{parameter world}
\rightarrow
\text{exact future map}
\rightarrow
\text{binary decision}
]

is a valid target-refinement chain.

Consequently parameter-world identification implies exact-future identification, which
implies binary-decision identification.

The frozen Phase-V audit found zero violations.

Current BAM-state identity is not inserted into that chain unless the particular
counterfactual is known to factor through current state.

## 4. Frozen BAM example

In the W1 climate-shift audit, one same-G survivor fiber in system
`S11_9x5_gap` contained 36 parameter worlds.

All 36 shared one complete current A/B/M/tau state, but the fixed climate transformation
produced:

- two exact future maps;
- two binary net-loss outcomes.

This is direct finite-world evidence of dormant parameter reactivation under a
structured counterfactual.

## 5. Consequence for experiment design

Evidence collection should be conditioned on the intended target.

If the goal is a future decision, measuring enough to identify current BAM state can be:

- unnecessary, when the future decision is already invariant across the survivor fiber;
- insufficient, when current-state aliases reactivate under the transformation.

The relevant stopping condition is instead

[
|D(S)|=1
]

for the declared survivor set (S), transformation and world universe.

## Boundary

This is elementary finite mapping logic, not new mathematics.

The BAM-specific contribution is the explicit demonstration that occurrence-conditioned
current mechanism equivalence and intervention-response equivalence can cross-cut each
other, including under a preregistered ecological transformation.
