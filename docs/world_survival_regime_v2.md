# World-survival regime forecast v2 — one-transition, distinct-world contract

## Why v2 exists

The frozen v1 protocol failed before biological response access.

V1 used graph-closure horizon n-1. In an undirected graph, a node then reaches its entire
connected component. Any world whose largest weak component contains a strict majority
of nodes therefore has

    median_horizon_reachable_fraction
    == largest_weak_component_fraction

and v1 horizon-realization ratio = 1.

Because the adequacy-complete ladder contains high-LCC worlds, v1 could not express
falsified_universe even though that was an allowed scientific outcome. Response-blind
NEON metadata also showed that multiple LCC target labels can collapse to the same
adjacency operator.

V2 corrects only those two structural defects.

## Frozen changes

### 1. One admitted transition

The structural audit horizon and the positive-occurrence compatibility horizon are both
one transition.

This is not a fitted dispersal time. It follows the declared world semantics: an edge is
one admitted local transition. The response-blind predictor asks how much of the world
available at the LCC scale is locally realizable in one transition.

### 2. One operator, one denominator weight

Exact duplicate adjacency matrices are collapsed before structural audit and before
survival fractions are calculated.

Alias world IDs remain recorded for provenance, but duplicate labels cannot multiply the
weight of one structural hypothesis.

## Unchanged rule

For every distinct falsifiable world:

    H_w =
        median_one_step_reachable_fraction
        / largest_weak_component_fraction

The cutoff remains exactly 0.5.

- H_w >= 0.5 -> predict survives
- H_w < 0.5 -> predict fails

System regime:

- no distinct worlds predicted to survive -> falsified_universe
- some but not all -> contracting
- all -> saturated

The cutoff is carried unchanged from v1. It is not chosen from NEON response-blind
forecast balance and cannot be changed after candidate forecasts or biological response.

## Adequacy remains separate

The eligibility gate still uses only:

- largest weak-component fraction;
- isolated-node fraction.

One-step horizon reachability is forbidden as an adequacy criterion in this protocol,
because it is the prediction variable.

## Response compatibility

The primary biological response remains only the ever-positive node set.

For each distinct world, every positive node is evaluated as a target while all other
positive nodes form the symmetric peer-source set. A world survives only if every target
has positive one-step support from at least one other positive peer.

This does not identify historical direction or ancestry.

## Non-retroactivity

V2 does not rescue or reinterpret:

- STOC;
- Southwest Louisiana;
- Tampa;
- the failed v1 NEON forecast;
- the closed EOG-WF prediction programme.

The first valid test of v2 must use a forecast fingerprint frozen before biological
response access.
