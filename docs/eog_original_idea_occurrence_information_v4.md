# Original EOG occurrence-information experiment — v4

## Question

The original EOG idea treated an occurrence as more than a local suitability label.

A positive occurrence also says that, under the unknown distribution-forming process,
the point was reached.

v4 asks how much that reachability meaning contributes under known truth.

## Candidate worlds

For each frozen v2 latent landscape, candidate worlds cross:

- every locally A/B-permissive node as a possible source;
- three barrier levels;
- three response-independent environmental traversability rules.

The true source is hidden from the inference.

Because all candidate worlds share the same A/B permissibility field, treating an
occurrence only as "locally viable" cannot distinguish these worlds.

Treating the same point as "must have been reachable from the candidate source" can.

## Sparse occurrence experiment

Truth-positive non-source nodes are revealed at:

- 10%;
- 25%;
- 50%;
- 100%.

Two nested spatial designs use the same number of points:

1. clustered near the truth source;
2. dispersed farthest-first.

The comparison asks whether the spatial arrangement of occurrence records changes their
information content even before genotype, abundance or absence data are supplied.

## Main outputs

- compatible source × barrier × analyst worlds;
- remaining source hypotheses;
- robustly impossible locally viable nodes;
- recovery of truth-unreachable nodes as robust impossibilities;
- false robust exclusions;
- exact world/source recovery after all positives.

This directly tests the original EOG claim that occurrence patterns contain hidden
reachability information that is lost when points are treated as independent local
suitability labels.
