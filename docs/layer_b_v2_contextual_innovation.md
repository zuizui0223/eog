# Layer-B v2 contextual innovation

## Current role

This is a **candidate prediction-facing representation**, not a new empirical claim and not a repair of Tampa. Layer A remains the exact scientific state.

The mechanism programme now gives two reasons to stop exposing an absolute node-level support summary by default:

1. Tampa's frozen Layer-B v1 became a static node-specific spatial/topology signature when all worlds remained compatible and the same state was reused across repeated visits.
2. The frozen 64-replicate known-truth factorial showed direct median harm from static repeated state under dynamic truth, while arbitrary label-dependent source encoding was also harmful. The generator-shift positive-median hypothesis was refuted.

## v2 representation

Prediction first uses the source-symmetric projection, then removes the prediction-facing state that was already present at a fixed pre-outcome reference context:

```text
Layer A exact state
    -> source-symmetric prediction projection S_t(node, feature)
    -> fixed pre-outcome reference S_0
    -> Layer-B v2 innovation I_t = S_t - S_0
```

The output has the same ten dimensions as the source-symmetric support summary, prefixed `delta_from_reference__`.

This choice is deliberately minimal. It does not concatenate absolute support with the innovation block. Therefore a node-specific component that is identical across contexts cancels algebraically rather than being left for a learner to ignore.

## Semantics

`I_t` means **change in the declared prediction-facing structural state since the fixed reference**, not movement probability, colonisation probability, occupancy probability, causal effect, or proof that the world set has changed for biological reasons.

For a scored context, `S_t` must be computed strictly before that context's response is opened. `S_0` must be fixed from information admissible before the first scored context.

A zero vector means only that the source-symmetric prediction-facing representation has not changed from reference. It does not establish ecological stasis.

## What it fixes by construction

- arbitrary source names/order: removed upstream by source-symmetric projection;
- node-static support signatures: exactly cancelled when present in both reference and current context;
- static repeated Layer B: yields all-zero innovation rather than a reusable node identifier;
- feature proliferation: remains ten dimensions rather than adding an absolute plus delta block.

## What it does not fix

- a badly declared finite world universe;
- world-set saturation itself;
- source semantics that are biologically inappropriate even if symmetrized;
- missing context refresh in Layer A generation;
- train/serve software or schema drift;
- learner-specific calibration problems;
- predictive usefulness in real data.

The existing predictive-state gate and contraction/saturation audit remain required. The innovation transform is downstream of those safeguards, not a replacement for them.
