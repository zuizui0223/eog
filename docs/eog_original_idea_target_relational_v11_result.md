# Original EOG target-relational sufficiency — v11 result

## Result

Seven of eight preregistered hypotheses were supported.

The refuted hypothesis is important:

> **When all three relational targets are requested together, the target quotient
> recovered all four topology worlds.**

So relational compression depends on asking a sufficiently specific ecological
question.

## Static map -> minimal relational information

v10 had four worlds with identical static A/B/M/G/marginal maps.

v11 treated individual relational quantities as measurements and asked for the exact
minimum subset sufficient for each target.

Across all **192** rows:

| target | target classes | exact minimum |
|---|---:|---:|
| first-passage signature | 3 | **1** |
| intervention signature | 3 | **1** |
| critical-node count | 3 | **1** |
| pairwise relation signature | 3 or 4 | **2** |
| joint relation + passage + intervention | 4 | **2** |

Every target was resolvable.  No target required the complete relational feature
library.

## Full topology is unnecessary for narrow targets

First-passage and intervention targets had only three classes in every row while the
edge topology had four identities.

The star and redundant worlds are a clean example:

- different edge topology;
- potentially different internal relation structure;
- same source first-passage depth;
- same single-node knockout outcome.

If the target is only first passage or knockout response, recovering the extra edge
identity is unnecessary.

## Cross-family evidence

The exact minima were not constrained to use measurements bearing the same name as the
target.

Canonical minima:

- first passage: one FP measurement;
- intervention: **one FP measurement**;
- critical-node count: **one FP measurement**;
- pairwise relation: one REL + one FP;
- joint suite: one REL + one FP.

For intervention, a cross-family minimum existed in **192/192** rows.

This means evidence should be judged by the target classes it separates, not by whether
its semantic label matches the target.

## No universal measurement order

There were **26 distinct canonical first measurements** across rows and target
families.

For the one-measurement FP-based targets, the canonical first measurement was:

- FP:N01 in 145 rows;
- FP:N02 in 41;
- FP:N03 in 6.

So even in this deliberately simple four-topology experiment there was no universal
single node to measure first.

## Q7 was refuted

The joint relational suite had four target classes in **192/192** rows.

Thus asking simultaneously for:

- full pairwise relation structure;
- first-passage structure;
- intervention response

was enough to distinguish all four topology identities.

This corrects an overly broad version of the target-quotient idea:

> **target-specific compression exists when the requested target is coarser than world
> identity; a rich enough bundle of targets can itself become world-identifying.**

## EOG design implication

The desired architecture is neither:

- static raster only;
- nor full network reconstruction by default.

It is:

static nodewise state
-> declare ecological target
-> add the smallest relational information sufficient for that target
-> stop if unresolved topology cannot change the target.

Only when the target suite itself separates all topology worlds is full topology
identity effectively required.
