# Penobscot real-system BAM bridge v1

## Role

This was a retrospective external bridge from the finite-world BAM programme to a real
dam-removal system. It was not fresh confirmatory evidence.

The design froze alewife as the focal species, smallmouth bass as a bidirectional
biotic-state proxy, physical/water-quality modules for A, and the historical dam
intervention sequence for M.

Only positive focal observations were allowed as hard ecological witnesses.

## Terminal status

The bridge stopped at response-blind Gate0 before any data-file payload was opened.

The live `FishPassage-Upstream` archive index did not contain the exact prospectively
required file `ARRA ZYDLEWSKI PIT DATA.accdb`.

Because the source contract prohibited source/file switching, the candidate was not
repaired or continued.
